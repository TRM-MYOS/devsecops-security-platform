How settings apply

Test connection checks the entered values without saving. Save repeats the check and applies the verified connection to the next sync.

Existing repositories

Repositories outside the new Owner stop being monitored. Their scan history and findings remain available. Add the new Owner's repository URLs in Repository Monitoring.

Configuration priority

Saved database settings take priority over Environment, .env and defaults. A Backend restart is not needed after saving.

Central Security Platform

Changing the target Owner does not change the trusted Central Workflow or its ALLOW/BLOCK rules. Each target still needs its security workflow and App access configured on GitHub.

Setting changes are recorded in the administrative audit under User Management.
